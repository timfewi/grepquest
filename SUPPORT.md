# Support

GrepQuest is a development prerelease maintained on a best-effort basis.

## Getting help

1. Read [README.md](README.md) and the focused documentation under `docs/`.
2. Run `just doctor` and the smallest relevant check from `just --list`.
3. Search existing GitHub issues before opening a new bug report.
4. Use the issue forms and include a minimal reproduction plus sanitized output.

Never include API keys, wallet material, private fixtures, recovery phrases, or
personal information in an issue. Security vulnerabilities must follow
[SECURITY.md](SECURITY.md) and must not be reported publicly.

## Support scope

Linux with the repository-pinned Nix development shell is the supported
contributor environment. Other operating systems, package managers, custom Sui
CLI versions, and public hosting configurations may receive community help but
are not currently supported by the maintainer.

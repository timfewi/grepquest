# Changelog

All notable changes to GrepQuest will be documented in this file. The format is
based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and releases
follow [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.0-dev] - Unreleased

### Added

- Deterministically judged GNU `grep` tutorial and terminal roguelite.
- Local SQLite progress, signed proof receipts, and badge rendering.
- Optional cosmetic OpenRouter integration with an offline fallback.
- Native development sandbox and digest-bound Firecracker backend.
- Optional Sui Move social package, public leaderboard reads, and preview-first
  transaction submission.
- Portable, source-backed Sui Move agent skills.
- Reproducible Direnv/Nix tooling for the pinned Sui CLI, Firecracker readiness
  checks, and opt-in real-KVM acceptance testing.
- A focused Firecracker guest-kernel configuration and fail-closed production
  host audit for jailer/cgroup prerequisites.
- A passing real-KVM boot path with explicit guest readiness, strict vsock
  acknowledgement parsing, read-only rootfs init tooling, and UID/GID isolation.
- Warning-free isolated Sui CLI configuration in the writable Direnv state
  directory.
- Reproducible host CLI release bundles with SHA-256 checksums and Go dependency
  license texts.
- Support, governance, citation, and production Firecracker documentation.
- Production Match Door vector/PNG brand assets derived from the selected logo.
- A responsive Living Terminal TUI with act-specific room scenes, balanced
  mission and command grids, the reviewed 60x60 ASCII Motion Ranger export, and
  reduced motion.
- A pinned, asset-directory-sandboxed ASCII Motion authoring workflow for
  development exports without adding a game runtime dependency.

# Changelog

All notable changes to GrepQuest will be documented in this file. The format is
based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and releases
follow [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.0-dev] - Unreleased

### Added

- Deterministically judged GNU `grep` tutorial and terminal roguelite.
- Local SQLite progress, signed proof receipts, and badge rendering.
- Optional cosmetic OpenRouter integration with an offline fallback.
- Native development sandbox and digest-bound Firecracker backend.
- Optional Sui Move social package, public leaderboard reads, and preview-first
  transaction submission.
- Portable, source-backed Sui Move agent skills.
- Reproducible Direnv/Nix tooling for the pinned Sui CLI, Firecracker readiness
  checks, and opt-in real-KVM acceptance testing.

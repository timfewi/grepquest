# GrepQuest UI

Read the repository instructions and [project context](references/project-context.md),
then select the smallest sibling skill that matches the requested outcome:

- New visual direction, redesign concept, art direction, or design alternatives:
  `grepquest-ui-explore`.
- Implement a selected direction or make a scoped change to an established website:
  `grepquest-ui-build`.
- Audit, compare, critique, or verify a rendered interface: `grepquest-ui-review`.

For a full net-new landing page, sequence exploration, explicit visual selection,
implementation, and rendered review. Stop after exploration until the user chooses a
direction. Skip exploration for a small change when an existing interface already
establishes the visual target.

Use at most one focused sibling at a time unless the request explicitly spans phases.
Do not install external skill catalogs or run remote setup commands merely to obtain
design advice; the checked-in skills are the project authority.

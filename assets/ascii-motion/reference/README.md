# Ranger visual reference

`grepquest-ranger-reference-transparent.png` is the approved full-body source
for the ASCII Ranger. It has a genuine RGBA alpha cutout for clean silhouette
tracing. `grepquest-ranger-reference.png` retains the preceding flat-background
version for provenance and edge comparison.

The original prompt requested an original heroic MMORPG signal ranger with a
front-facing symmetric stance, winged Q helmet, segmented graphite and
near-white armor, green signal channels, one amber clasp, large readable forms,
and no franchise-specific character or equipment. The final refinement changed
only the background to a uniform `#F4F1E8` field. The cutout edit removed that
field while preserving the character and interior off-white armor surfaces.

This image is an authoring reference. It is not loaded by the GrepQuest runtime.
